# MaxWorkflw

MaxWorkflw is a multi-agent workflow project: an Opus orchestrator plans and delegates to Sonnet leads and Haiku workers.
The team ships apps that deploy to Vercel or Cloudflare, within a 24-hour deadline and a 15-agent cap.
Agent rules are in [CLAUDE.md](CLAUDE.md); the full operating prompt is [docs/ORCHESTRATOR_PROMPT.md](docs/ORCHESTRATOR_PROMPT.md).
